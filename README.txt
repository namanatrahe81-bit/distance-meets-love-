PREVIEW ON ANDROID / ACODE
1. Download and extract the ZIP.
2. Keep the index.html file and the images folder together.
3. Open the folder in Acode, open index.html, and use Preview.
4. Enter 0602 on the lock screen.

PUBLISH ONLINE
1. Create a GitHub repository.
2. Upload index.html and the whole images folder (with both JPG files).
3. Open repository Settings → Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the published site URL to appear in Pages settings.
6. Open the published URL and test the passkey before sending it.

PRIVACY
The passkey is a cute front-end lock, not strong security: the code can be found by someone who inspects the website files. A public static website can also expose the photo files directly. Only publish these pictures if Jiya is comfortable with them being public; for real privacy, use a private sharing option.
