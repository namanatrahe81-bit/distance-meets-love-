STYLE
Cream / satin-inspired background, keypad lock screen, memories gallery, letter page, Spotify “Our Songs” page, and a final love message.

HOW TO OPEN ON ANDROID
1. Extract this ZIP.
2. Keep index.html and the images folder together.
3. Open the extracted folder in Acode.
4. Open index.html and use Preview.
5. Enter 0602.
6. Open “Our songs” and press play in a Spotify card.

PUBLISHING
Upload index.html and the entire images folder to the same GitHub repository. Enable GitHub Pages in Settings → Pages and choose the main branch / root folder.

SPOTIFY
Playback depends on Spotify and the listener's account/region. The site embeds Spotify players; it does not host music.

PRIVACY
The keypad is a visual front-end lock, not strong security. If published publicly, the passcode and image files can be discovered. Only publish photos with Jiya's consent.
